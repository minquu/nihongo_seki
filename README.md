# nihongo_seki

일본어 수업용 **랜덤 조 편성 레이스** 웹앱입니다.
참가자 이름으로 공을 만들고, 장애물을 지나 결승선에 도착한 순서대로 조를 편성한 뒤 분단별 자리까지 배치합니다.

🔗 https://minquu.github.io/nihongo_seki/

## 기능
- 이름 입력 → 인원수만큼 공 생성, 물리 기반 레이스 (matter-js)
- 그룹당 인원 / 그룹 수 지정, 남는 인원 처리 방식 선택
- 도착 순서대로 조에 쌓이고, 인원이 차면 다음 조로 자동 이동
- 분단별 팀 자리 배치 (기본: 1분단 2팀 · 2분단 1팀 · 3분단 2팀), 드래그/클릭으로 자리 교환
- 명단 저장/불러오기, 지난 결과 보기 (브라우저 localStorage)
- 결과 복사, 인쇄

## 로컬 실행
```bash
npm install
npm run dev
```

## 배포
`main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 자동 배포합니다.
